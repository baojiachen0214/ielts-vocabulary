# 雅思词汇练习

网址：https://baojiachen0214.github.io/ielts-vocabulary/

选择词库后听音拼写，提交后显示中文和词性。错词可单独复习，未完成的练习可以继续。

发音使用有道词典录音。页面会提前加载当前词和后续 5 个词，复用已缓冲的播放器；首次打开及网络较慢时仍可能需要等待。

学习进度保存在当前浏览器的 localStorage，音频包单独保存在 IndexedDB。作答记录不会上传到 GitHub。发音播放及预加载会向选定音源发送单词。

从本地文件迁移：先在原页面的「设置」中导出备份，再打开网站，在「设置」中导入。同一浏览器通常会保留进度；换设备、换浏览器或清理网站数据后需要重新导入备份。

网站为单个静态 HTML 文件。将更新推送到 main 分支后，GitHub Pages 会重新发布。
