# 雅思词汇练习

网址：https://baojiachen0214.github.io/ielts-vocabulary/

选择词库后听音拼写，提交后显示中文和词性。错词可单独复习，未完成的练习可以继续。

发音使用有道词典录音。页面会提前加载当前词和后续 5 个词，复用已缓冲的播放器；首次打开及网络较慢时仍可能需要等待。

学习进度保存在当前浏览器的 localStorage，音频包单独保存在 IndexedDB。作答记录不会上传到 GitHub。发音播放及预加载会向选定音源发送单词。

从本地文件迁移：先在原页面的「设置」中导出备份，再打开网站，在「设置」中导入。同一浏览器通常会保留进度；换设备、换浏览器或清理网站数据后需要重新导入备份。

网站为单个静态 HTML 文件。将更新推送到 main 分支后，GitHub Pages 会重新发布。

## 词库与频次

首页提供 2024–2026 的 Part 1、Part 4 两个跨年去重词库，分别有 511、733 个拼写，按原年份词表频次之和排序。去重仅合并相同拼写，不把单复数合并为一个答案。

“按年份或剑桥选词”保留原有年份词库，并新增剑桥 8–21 的 Part 1（368 词）、Part 4（513 词）答案词库。它们来自本地模考项目的 56 套听力资料：检查 1,120 道题后收录 938 道单词填空答案，保留可接受的单词拼写变体，带来原词库没有的 469 个拼写。

剑桥频次按不同套题数计算，同一套题内重复出现只计一次。它与原年份词表的频次分开统计，不能解释为真实考试概率。册号不等于考试年份；有套题信息的显示册号、Test、Part 和题号，没有套题信息的年份词表明确标注未提供套题号。

数字、日期、短语、选择题选项字母和待核对的专名未进入新单词库。只发布单词及出处元数据，不发布模考题目全文。提取统计见 data/corpus-audit.json。词义和词性来自原词表或补充的简明词典释义，并非逐题全文翻译。

重新提取现有本地模考答案：

```sh
python3 scripts/build_vocabulary.py --mock-root /path/to/mock-project
```

汇总入口只展开真实来源词库，不写入额外的虚拟进度。已有任一年份的已练单词会在对应跨年汇总中跳过；从汇总作答时，进度同步到对应的原年份词库。旧存档格式和浏览器存储键保持兼容。
